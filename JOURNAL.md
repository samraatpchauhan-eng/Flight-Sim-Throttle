# September 4: Project planning and CAD work

Starting off the project, this is something I've wanted to do for a while now. As someone who dreams of building a full flight sim cockpit one day, I feel that designing my own throttle for flight simming will help with that process. I've decided to switch from Autodesk Fusion to Onshape, so using a different CAD software will also be a learning experience for me, however as someone who is comfortable with the basics of CAD, this shouldn't be that bad. Dimensions wise, I took inspo from the Thrustmaster a320 sim kit, as I want this to be something easy to use on the desk, without taking up too much space.
